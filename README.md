# aichat

- `SkyLinks/HANDOVER.md`: **start here** for the current state, people, file locations and next steps.
- `SkyLinks/`: **Sky Links**, an 18-hole multiplayer mobile golf game for Unreal Engine 5.8. Start with `SkyLinks/README.md`.
- `golf/`: Pocket Links, an early single-file browser prototype.
- `uai32/`: **Sentovara µAI-32**, a trainable neural network whose executable plus saved model fits in 32,768 bytes. Start with `uai32/README.md`.
- `uai32-voice/`: voice-feasibility study for µAI-32 (front-end bytes, few-shot benchmark, protocol, enrolled-speaker pilot kit). Start with `uai32-voice/README.md`.
- `uai32-swarm/`: **Flat Swarm V1**, the Mini Sentinel specialist swarm experiment, frozen at commit `530ec02` (tag `flat-swarm-v1`) as the control baseline. The project continues, with its development history and provenance, at https://github.com/jonny5isalive5/mini-sentinel-swarm. Start with `uai32-swarm/README.md` and `uai32-swarm/FINAL.md`.
