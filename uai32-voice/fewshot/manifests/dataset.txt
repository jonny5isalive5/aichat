Enrolled-speaker simulation is impossible for the tested command sets
---------------------------------------------------------------------
The challenge's setting enrols one speaker with 5 recordings of each command.  Speakers with >= n recordings of EVERY
word of the set:
  yes/no/stop:      n=1: 176   n=2: 51   n=3: 7   n=4: 0   n=5: 0
  up/down/go:       n=1: 187   n=2: 54   n=3: 6   n=4: 1   n=5: 0
  yes/no/stop/go:   n=1: 131   n=2: 41   n=3: 3   n=4: 0   n=5: 0
Statement: NO speaker in this dataset has 5 recordings of each word of any tested command set (yes/no/stop,
up/down/go, yes/no/stop/go), so the benchmark could not enrol and test the same speaker; every reported number is
speaker-independent (enrolment speakers are excluded from dev and test).  For completeness: over all 56 word triples
the largest number of speakers with >= 5 recordings of every word is 2 (triple go/left/yes), i.e. the report's phrase
"no speaker has >= 5 recordings of each word in any triple" is exact for the tested triples and the 4-command set but
not for the untested triple go/left/yes (2 speakers, too few for an experiment).
