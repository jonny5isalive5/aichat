# Few-shot spoken-command recognition on mini_speech_commands (speaker-independent): summary
Enrolment = 5 recordings per command from random speakers; all dev/test recordings come from OTHER speakers (harder than the challenge's enrolled-speaker setting).
Per draw: 100 fresh test recordings per command, 1000 dev + 1000 test unfamiliar recordings (200 per other word).  Threshold policy: accept if score > thr;
per-draw thr = the value that admits <=1% of that draw's dev negatives; fixed thr = median per-draw dev threshold over SEPARATE dev seeds (101-110), frozen before testing.
Recall = accepted AND correct command.  Wilson 95% intervals are on counts pooled over draws (draws share recordings, so they are optimistic; the ±sd across draws is also given).
