# Licensing and attribution

## Project scope

The owner selected **Apache-2.0** for the project code and release documentation in `uai32/` during
release preparation. See [LICENSE](../LICENSE) and [NOTICE](../NOTICE). The license is an added release
overlay: the original audited commit had no license file. It does not relicense third-party datasets,
host libraries, development tools, or the unrelated projects elsewhere in this repository.
The original evidence archive is preserved with its source and toolchain attributions intact.

## Iris

R. A. Fisher (1936), *Iris* [Dataset], UCI Machine Learning Repository,
[DOI 10.24432/C56C76](https://doi.org/10.24432/C56C76).
The [UCI source](https://archive.ics.uci.edu/dataset/53/iris) identifies the dataset as
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
`data/iris.data` is the preserved source data. `gen_data.py` shuffles and converts it into labelled
120-row training and 30-row test text files. One test row duplicates a training row in the source.
These transformations and that caveat are retained; the data is not relicensed under Apache-2.0.

## MNIST

Yann LeCun, Corinna Cortes and Christopher J. C. Burges, *The MNIST database of handwritten digits*.
See the [dataset homepage](https://yann.lecun.org/exdb/mnist/) and the
[CVDF mirror](https://github.com/cvdfoundation/mnist).
The preserved downloader identifies MNIST as CC BY-SA 3.0; this attribution is part of the audited source.
The release package includes no MNIST images, labels, source archives or generated text dataset files.
Reproduction downloads the four hash-pinned archives from the documented CVDF/OSSCI mirrors and uses
2×2 average pooling with rounding to convert 28×28 images into 14×14 integer features.
Consult the dataset's applicable terms when redistributing dataset material; the project software
license does not grant additional rights in the data.

## Synthetic data, host libraries and verification tools

Spirals and rings are generated by this project's seeded `gen_data.py`; their original generated files
are preserved. The executable dynamically uses the host's C library, math library and dynamic loader.
Those libraries, GCC, GNU binutils, Python and NumPy are not bundled or relicensed. Their dependency
roles and exclusions are documented in [REPRODUCE.md](REPRODUCE.md).
